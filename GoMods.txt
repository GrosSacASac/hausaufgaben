Defer

A defer statement defers the execution of a function until the surrounding function returns. Deferred function calls are pushed onto a stack

Can be used to close files, change the return value of a function

Pointers


var p *int

The & operator generates a pointer

i := 42
p = &i

The * operator denotes the underlying value.

fmt.Println(*p) // read i through the pointer p
*p = 21         // set i through the pointer p

====================


Slices

 dynamically-sized, flexible view into the elements of an array.

The type []T is a slice with elements of type T.

high is excluding

low defaults to 0 and hight defaults to array length
a[low : high] // (a is an array)
var s []int = primes[1:4]
q := []int{2, 3, 5, 7, 11, 13} // slice literal (size is not provided)
// creates an array and immediately returns its view

The make function allocates a zeroed array and returns a slice that refers to that array:

b := make([]int, 0, 5) // len(b)=0, cap(b)=5
b = append(b, 2, 3, 4)

append returns a new slice. If the backing array of s is too small to fit all the given values a bigger array will be allocated. The returned slice will point to the newly allocated array. 



The capacity of a slice is the number of elements in the underlying array, counting from the first element in the slice.

expressions len(s) and cap(s).

LENTH <= CAPACITY

You can extend a slice's length by re-slicing it, provided it has sufficient capacity.
